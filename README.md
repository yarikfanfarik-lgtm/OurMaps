# OurMaps 🗺️

OurMaps — независимое Android-приложение карт без Google Maps и Яндекс Карт как картографической основы.

## Что уже заложено

- карта на базе OpenStreetMap;
- простой главный экран;
- строка поиска сверху;
- история последних мест;
- кнопка ИИ рядом с поиском;
- нижняя панель «Что интересного рядом?»;
- режимы маршрута: пешком, машина, автобус, метро;
- геолокация пользователя;
- ручной/автоматический режим рекомендаций;
- настройка порога обновления рекомендаций: 1 / 2 / 5 км.

## План проекта

1. **Карта** — собственный стиль, слои зданий, зелени, дорог и POI.
2. **Поиск** — собственный backend на данных OpenStreetMap.
3. **Маршруты** — пешие, автомобильные и мультимодальные.
4. **Общественный транспорт** — автобусы, трамваи, метро и пересадки.
5. **AR-навигация** — стрелки поверх реального мира.
6. **ИИ-рекомендации** — места рядом, подборки и запросы обычным языком.
7. **Экономия батареи** — автоматическое обновление рекомендаций только после заметного перемещения; ручной режим полностью отключает фоновые рекомендации.
8. **Офлайн** — локальный кэш и позже полноценные офлайн-регионы.

## Источники данных

Базовая география проекта — OpenStreetMap. В production публичный tile-сервер OSM не следует использовать как массовый backend приложения: для OurMaps планируется собственная инфраструктура тайлов/кэша и отдельные сервисы поиска и маршрутизации.

## Запуск

Проект использует Flutter. Если платформа Android ещё не сгенерирована, в корне проекта выполните:

```bash
flutter create . --platforms=android
flutter pub get
flutter run
```

Для APK:

```bash
flutter build apk --release
```

## Лицензии и атрибуция

Данные OpenStreetMap распространяются по Open Database License (ODbL). При публикации приложения необходимо сохранить требуемую атрибуцию и соблюдать условия лицензии используемых данных.

`flutter_map` используется как клиент отображения карты; он не является картографическим провайдером OurMaps.
